Design notes

Spring backend

  • The "view grades" page in Spring has gotten huge. Teachers would be better served by a teacher view on the frontend.
  • Leave the legacy pages in place rather than ripping them out.
  • Grading still needs a proper design before more gets built on it.
  • The assignment tracker spans about 20 pages across several years. Starting from scratch would be cleaner but is too much work, so we're improving what's there.
  • AI grading uses a rubric out of 1 point.
  • Add only the CRUD operations admins actually need, not every possible one.

Pages frontend

  • Submission screens for both graders and teachers.
  • Teachers should only ever need the frontend to do their work.
  • That includes starting AI grading from the frontend.

How we're working

  • PRs should remove sharp edges, not add band-aids.
  • An AI grade and a student or grader grade should sit side by side. Neither one overwrites the other.
  • Fix bad data at the source. If a record is wrong, there should be an admin way to correct it.
